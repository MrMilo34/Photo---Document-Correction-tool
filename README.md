# MeshDoctor v1.6.11

## What’s new in v1.6.11

- Fixed Label Maker camera **height resizing** so the **top** and **bottom** neon pink `›` handles now resize the guide **together symmetrically**, similar to the mirrored width behavior.
- Improved **bottom curve editing** by prioritizing mesh-point dragging over nearby height-handle dragging, so the lower guide points are easier to shape.
- Reduced camera/overlay workload for smoother phone performance by lowering the live camera resolution, lowering the overlay sampling load, and keeping the same general aspect ratio.
- Width handles, contour mesh points, auto-capture, and sequential label naming are all preserved.
