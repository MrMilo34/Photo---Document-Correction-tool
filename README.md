# MeshDoctor v1.6.12

## What’s new in v1.6.12

- Makes the Label Maker camera **resize handles easier to grab** by increasing handle hit area, shrinking point hit priority, and preferring handle drags when you are close to a resize control.
- Captured label camera photos now **carry the shaped curved guide forward** as the starting deformation mesh for flattening/stitching, instead of only saving a plain width crop.
- Further reduces live camera latency by lowering live preview resolution and frame rate, reducing overlay refresh rate, reducing overlap-sampling load, and using lighter captured-section sizing.
- Keeps the width/height resize handles, mirrored points, auto capture, and sequential naming behavior.

PWA cache key: `meshdoctor-v1.6.12`.
