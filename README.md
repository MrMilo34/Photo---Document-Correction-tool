# MeshDoctor v1.3

## Changes
- Renamed the app from **DocMesh** to **MeshDoctor**.
- Updated the splash artwork so the document transitions into a hand-drawn cityscape, reflecting both document and photo restoration.
- Keeps the v1.2 editor improvements: 1x panning, interaction-aware hidden controls, Undo, neon mesh Correct Image button, drag-only adjustment sliders, and Automatic / Document / Photo restoration choices.
- Updated PWA metadata, cache keys, and branding for the new name.

## AI Assisted
This build keeps the current on-device/local restoration modes. A true cloud semantic restoration layer still requires a secure backend endpoint; an API key should never be embedded in the GitHub Pages app.

## Upload
Replace the current GitHub Pages repository files with the contents of this package. After deployment, refresh or reinstall the PWA so the new MeshDoctor name, splash, and cache are picked up.
