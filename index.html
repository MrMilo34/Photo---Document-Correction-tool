MeshDoctor v1.6.48

The mesh points define the correction boundary. MeshDoctor can straighten photographed paperwork or keep a full photo framed for restoration.

AI Assisted uses secure AI image restoration when available. If it is unavailable, MeshDoctor automatically uses its on-device restoration fallback.

Create a PDF lets you combine images with selected pages from existing PDFs, omit pages you do not want, reorder everything, edit pages through MeshDoctor, and save a new PDF.

v1.6.48: switches loop identity to a dedicated full-width live-frame reference captured alongside the first HQ shot, so loop handoff no longer depends on HQ still-image framing. It also loosens HQ auto-capture from ‘perfect only’ to ‘high-confidence’, allowing earlier keyframes, softer duplicate rejection, and slightly faster cadence while keeping loop completion strict.

v1.6.47: introduces guided confidence capture: the full frame uses 10/20/40/20/10 zoned recognition for mapping and loop detection, the central 40% supplies HQ detail, and Pass 2 displays a red→orange→yellow→lime→green confidence rail with a live position marker. Pass 2 now tracks against the fixed Pass 1 map with circular seam-aware matching.

v1.6.46: introduces the central-detail capture model, using a wide tracking frame while concentrating final HQ pixels in the flatter middle portion.

v1.6.45: updates the Android icon, fixes the HQ ghost to show the actual prior blue-frame capture, and adds text-region HQ starvation protection.

v1.6.44: adds folder-aware output naming and the dedicated Camera / Gallery / PDF source chooser.

v1.6.43: standardizes automatic output naming across PDFs, normal images, Side by Side images, and Label Maker. File Output now exposes independent PDF, Image, and Label next-name fields with counters that advance separately after each successful save.

v1.6.42: restores a dedicated Correct Image action chooser with separate Camera and Gallery actions, while keeping Side by Side and the Label Maker changes untouched.

v1.6.41: simplifies the home screen around Correct Image, adds Side by Side assembly with horizontal/vertical layouts and drag ordering, and routes the finished composite into the normal MeshDoctor correction and naming workflow.

v1.6.40: restores continuous tracking through dense repeated label text, uses multi-signal loop recognition so Pass 1 reliably hands off to Pass 2, and fixes the wide-label tiled AI compositor so later AI sections can no longer erase/collapse the rest of the panorama. The full-width original is retained beneath overlapping AI tiles as a fail-safe.

v1.6.39: hybridizes the strongest v1.6.27 panoramic behavior with the current two-pass map: live tracking stays continuous through HQ captures, the live map is authoritative for final HQ placement, small ambiguous movement is accepted while large repeated-text jumps stay blocked, and the forgiving v1.6.27 seam feather is restored. It also adds purple asymmetric resize handles beside the pink symmetric handles and repeatedly re-syncs the camera overlay layout to eliminate the cyan sizing state.

v1.6.38: introduces two-pass panoramic mapping. Pass 1 builds the live 360° label map; after the first loop, Pass 2 re-matches live frames to that map, targets weak HQ coverage, and places HQ captures by live-map coordinates. It also removes the large HQ-photo overlay.

v1.6.36: fixes full-rotation detection by fingerprinting the first accepted HQ capture and using shift-tolerant correlation to stop on the first genuine return to the starting label area instead of continuing into a second lap or false-triggering on a different text/front panel.

v1.6.35: hardens live Label Maker tracking around dense/repeating text, rejects implausible tracking jumps, freezes the ghost to the last accepted HQ capture only, pauses live tracking during the HQ shutter, and builds final panorama pixels/placement primarily from the accepted HQ keyframes instead of trusting a corrupted live map.
